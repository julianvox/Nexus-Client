# Nexus (Fabric, Minecraft 26.3)

Derleme:  gradle wrapper  ->  gradlew.bat build   (Java 25)
Çıktı:    build/libs/nexus-1.0.0.jar  -> .minecraft/mods (Fabric API ile birlikte)

Menü:     Sağ Shift (ESC > Seçenekler > Kontroller > Tuş Atamaları > Nexus - Genel)
Tuşlar:   Her modülün tuşu ESC > Kontroller > Tuş Atamaları altındaki "Nexus - ..." kategorilerinde
Komutlar: .yardım
Profiller: .minecraft/config/nexus/<ad>.json

Arayüz: mor-sarı-siyah-beyaz tema, animasyonlar (başlıkta FX düğmesi), ince yazı tipi (başlıkta Aa düğmesi).
Yazı tipi: Roboto Light (SIL Open Font License) - assets/nexus/font/OFL-Roboto.txt
